Arriving on the project

As a new member of the project i needed to set foot in systems i didn't know about.

So the first step was to take the current bot's behavior, cut it in pieces to understand what the last GPP left behind.

Then it was time for prototyping

First i tried to recreate the bot from start using the current system and adapting it using my skills

Then step by step i was adding more complexity to his behavior with new moves that the old bot couldn't use.

Ball's prediction

The bot needed a prediction system to know where the ball will be at any time in space.

First i made a system that predicted ball positions by calculating gravity, bounces, etc. but the approximations of complex calculations made it too uncertain if the prediction was too long.

I then replaced that system by a physics based one.

By duplicating every gameplay important collider in an async scene at the start of the game. And every time anyone needs to know future ball positions he can ask that scene to predict, the scene then takes currents ball's infos (linear velocity, angular velocity, position, etc...) and simulates for the asked amount of frame.

I made this system directly in our Physics Utils so anyone might use it.

Altrough this system is way more accurate than the previous one, it can rapidly cost too much performance especially in multiplayer games. So it needed some optimisation, i reduced at minimum the amount of time it was used and sliced the prediction to several frames to relieve the server from doing too many steps per frame.

With this all done i had a pretty good roster of tools to make an interesting bot's behaviour

R&D

The more i wanted to add things to the bot the more i saw the limitations of the current system, so it was the right time to start making some research on bot's behavior.

With some research, i found behaviour tree being the right tool to make what i wanted

So we added Unity Behavior to the project and now the new step was ...

Learning behaviour trees

The first step was to remake what i have done before but entirely with behaviour trees.

For that i needed to create several custom nodes for all actions the bot could make, and also needed flow nodes to make him take decisions.

After i finished remaking the behaviour with the trees i had a good pipeline installed, i can now iterate faster without any limitation.

So i started the last step ...

Sequences

I have a bot who has pretty good placement, strategy over attack and defending state all over the game but now i want him to use special tactics at the right point in time that players can learn from.

Those tactits differ from base behavior cause when started the base behaviour is stopped to let place to the current tactic.

For that i made action nodes that take time and run actions one after another until they all succeed or any fails.
